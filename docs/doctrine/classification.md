# Klasifikasi dan Tier

## Klasifikasi

**PREVIEW — OPEN REDISTRIBUTION** adalah default per direktif produksi v2. Klasifikasi ditampilkan jelas pada cover dan header dokumen, dan pada header dashboard.

Catatan yang menyertai edisi PREVIEW:

> PREVIEW edition: open redistribution permitted with attribution. For Tier-A Client Edition, contact issuer for activation protocol.

## Tier

| Tier | Nama | Status |
|---|---|---|
| B | Preview / Market | Berjalan |
| A | Client Edition (HUMINT-graded) | Menunggu protokol aktivasi klien |

Tier A belum berjalan. Dashboard tidak menampilkan jalur Tier A sampai protokol aktivasi diterima, dan skema data menolak `CLIENT_TIER_A` yang tidak disertai tier `A`.
